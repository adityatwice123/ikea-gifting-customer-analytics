# data

Raw and processed files are not committed (the raw CSVs are about 90 MB).

**Get the data:** Online Retail II, UCI Machine Learning Repository, donated by Daqing Chen.
Licence: CC BY 4.0. https://archive.ics.uci.edu/dataset/502/online+retail+ii

Place the two sheets, exported as CSV, in `data/raw/` named:
- `online_retail_II page 1.csv`
- `online_retail_II page 2.csv`

`data/processed/customer_segments.csv` (one row per customer) is small enough to keep in the repo.
